# Описание

Программа создана для управления роботом через графический интерфейс. Ядро написано на C++, интерфейс пользователя — на Tkinter.

## 1 Структура системы 

```
┌─────────────────────────────────────┐
│        Python: ui.py (Tkinter)      │
│  Сборка │ Управление │ Позиция      │
└─────────────────┬───────────────────┘
                  │ 
                  ▼
┌─────────────────────────────────────┐
│     C-API (c_api.cpp)               │
│  rm_create_manipulator, rm_add_*    │
│  rm_set_direction, rm_calculate_*   │

                  │
    ┌─────────────┼─────────────┐
    ▼             ▼             ▼
```

## 2 Структура отдельных частей

### 2.1 Иерархия классов C++

```
MovableLink (базовое звено)
    ├── Gripper  (захват с углом раскрытия)
    └── Camera   (камера с углом обзора)
```

1. MovableLink
Описание: базовый класс звеньев - просто стержень. 
Характеристики: номер, длина и положение в пространстве, задаваемое через угол относительно оси предыдущего звена (pitch, yaw, roll).
Действия: добавить, удалить, рассчитать позицию.

2. Gripper
Описание: захват - стержень с клешней. 
Характеристики: как у MovableLink + угол раскрытия клешни.
Действия: как у MovableLink + раскрыть на клешню на заданный угол, открыть, закрыть клешню.

3. Camera
Описание: камера на стержне 
Характеристики: как у MovableLink + угол обзора.
Действия: как у MovableLink + сделать снимок.

4. Manipulator
Описание: робот целиком.
Характеристики: совокупность характеристик всех звеньев.
Действия: совокупность действий всех звеньев.

5. ElementaryMove
Описание: базовое движение.
Характеристики: номер звена, конечные значения угла поворота звена относительно предыдущего, валидность движения (вычисляется в Manipulator в 
checkCollision)
Действия: двигает заданное звено до нужного угла (задается конечный угол после движения), проверяет возможность такого положения (не столкнулись ли
звенья).

6. Movement
Описание: набор базовых движений.
Характеристики: набор базовых движений (массив).
Действия: выполняет набор базовых движений, вычисляет позицию последнего звена.

### 2.2 C-API

C-API (`c_api.h`, `c_api.cpp`) предоставляет функции с префиксом `rm_`, принимающие непрозрачный дескриптор `RM_Manipulator` (указатель на объект `Manipulator`). Исключения C++ перехватываются и преобразуются в коды возврата: 1 — успех, 0 — общая ошибка, -1 — ManipulatorException (нарушена цепочка звеньев).


## 3. Функции

### 3.1 Процесс использования

1. **Инициализация**: `rm_create_manipulator()` создаёт экземпляр манипулятора.
2. **Сборка**: добавление звеньев через `rm_add_link`, `rm_add_gripper`, `rm_add_camera`. ID образуют цепочку: для ID=1 предыдущее звено 0; для ID>1 — предыдущее (ID−1).
3. **Управление**: изменение положения в пространстве (`rm_set_direction`), открытие/закрытие захвата (`rm_open_gripper`, `rm_close_gripper`), снимок камерой (`rm_take_photo`).
4. **Запросы**: вычисление позиции звена (`rm_calculate_position`) и вывод структуры в консоль (`rm_print_structure`).
5. **Завершение**: `rm_destroy_manipulator()` освобождает ресурсы.

### 3.2 Вычисление позиции

Координаты звена в глобальной системе отсчёта вычисляются следующим образом:

1. Проходим по цепочке звеньев от базы (prev_id=0) до целевого звена по `prev_id_`.
2. Если какое-либо промежуточное звено отсутствует, срабатывает `ManipulatorException`.
3. Для каждого звена в цепочке добавляем приращение координат по формуле:
   - dx = r · cos(yaw) · sin(pitch)
   - dy = r · sin(yaw) · sin(pitch)
   - dz = r · cos(pitch)
4. Проверяем столкновения: если расстояние между звеньями меньше 0.1, срабатывает `std::runtime_error`.
