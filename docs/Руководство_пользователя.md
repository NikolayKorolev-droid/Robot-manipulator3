# Руководство пользователя Robot Manipulator

Это руководство предназначено для конечных пользователей, не знакомых с внутренним устройством программы.

---

## 1. Назначение программы

**Robot Manipulator** — программа для моделирования робота-манипулятора. С её помощью можно:

- собирать цепочку звеньев (звенья, захваты, камеры);
- управлять ориентацией звеньев;
- открывать и закрывать захваты;
- делать «снимки» камерами;
- вычислять координаты концов звеньев в пространстве.

---

## 2. Требования и установка

### 2.1 Что нужно для работы

- **Windows** (64-разрядная);
- **Python 3** (рекомендуется 3.10 или новее);
- Файл **RobotManipulator.dll** (собирается из исходников или поставляется вместе с программой).

### 2.2 Сборка DLL (если её ещё нет)

1. Установите среду разработки:
   - **Вариант A**: Visual Studio с C++ (запустите «x64 Native Tools Command Prompt for VS»).
   - **Вариант B**: MSYS2 с пакетом `mingw-w64-x86_64-gcc`.
2. Откройте командную строку и перейдите в папку `build`:
   ```
   cd путь\к\проекту\build
   ```
3. Запустите скрипт сборки:
   - для Visual Studio: `build_dll.bat`;
   - для MinGW: `build_dll_mingw.bat`.
4. Файл `RobotManipulator.dll` появится в корне проекта или в папке `build_objs`.

### 2.3 Запуск программы

1. Откройте командную строку.
2. Перейдите в корень проекта:
   ```
   cd путь\к\проекту
   ```
3. Запустите:
   ```
   python python\ui.py
   ```
4. Откроется окно «Robot Manipulator UI».

## 3. Интерфейс программы

Окно содержит **три вкладки**.

### 3.1 Вкладка «Сборка манипулятора»

Служит для добавления звеньев.

| Поле | Описание |
|------|----------|
| **Тип звена** | MovableLink (обычное звено), Gripper (захват), Camera (камера) |
| **ID** | Уникальный номер звена (целое число ≥ 1) |
| **Длина r** | Длина звена в условных единицах |
| **Pitch, Yaw, Roll** | Углы ориентации относительно предыдущего звена (в радианах) |
| **Доп. параметр** | Для Gripper — угол раскрытия; для Camera — угол обзора (field of view) |

**Правило цепочки**: ID звеньев должны идти подряд (1, 2, 3, …). Первое звено (ID=1) привязано к базе; каждое следующее — к предыдущему.

**Действие**: нажмите кнопку «Добавить звено». Добавленные звенья отображаются в списке ниже.

### 3.2 Вкладка «Управление»

Служит для изменения позы и управления захватами/камерами.

| Действие | Описание |
|----------|----------|
| **Установить ориентацию** | Введите ID звена и новые значения Pitch, Yaw, Roll, нажмите кнопку |
| **Открыть захват** | Введите ID захвата и угол раскрытия, нажмите «Открыть захват» |
| **Закрыть захват** | Введите ID захвата, нажмите «Закрыть захват» |
| **Сделать снимок (Camera)** | Введите ID камеры, нажмите кнопку (сообщение выводится в консоль) |

### 3.3 Вкладка «Позиция/структура»

| Действие | Описание |
|----------|----------|
| **Рассчитать позицию** | Введите ID звена, нажмите кнопку. Координаты x, y, z появятся на экране |
| **Печать структуры в консоль** | Выводит описание всех звеньев в окно консоли, из которой запущена программа |

---

## 4. Типичный сценарий работы

1. Откройте вкладку «Сборка манипулятора».
2. Добавьте звено 1: тип MovableLink, длина 1.0, углы 0.
3. Добавьте звено 2: тип MovableLink, длина 1.0, углы 0.
4. (По желанию) Добавьте Gripper (ID=3) или Camera (ID=3) в конец цепочки.
5. Перейдите на вкладку «Управление» и измените углы (например, Pitch = 0.5) для нужного звена.
6. Перейдите на вкладку «Позиция/структура» и рассчитайте позицию конца цепочки (последнего звена).

## 5. Возможные ошибки и их решение

| Ситуация | Причина | Решение |
|----------|---------|---------|
| «RobotManipulator.dll не найден» | DLL не собрана или не в нужной папке | Соберите DLL (см. раздел 2.2) и поместите её в корень проекта или в `build_objs` |
| «ID звена должен быть не менее 1» | Введён ID ≤ 0 | Используйте положительные целые числа |
| «Звено с таким ID уже существует» | Повторное добавление звена с тем же ID | Выберите другой ID |
| «Предыдущее звено не найдено» | Пропущен ID в цепочке (например, добавлено 1 и 3, без 2) | Добавляйте звенья по порядку: 1, 2, 3, … |
| «Нарушена цепочка звеньев» | При расчёте позиции отсутствует промежуточное звено | Проверьте, что все звенья от 1 до нужного ID добавлены |
| «Не удалось установить ориентацию» | Звено с указанным ID не существует | Проверьте ID в списке добавленных звеньев |

---

## 6. Единицы измерения

- **Углы** (Pitch, Yaw, Roll, угол раскрытия, FOV) задаются в **радианах**.
- **Длина** (r) — в произвольных условных единицах (например, метрах).
- **Координаты** (x, y, z) выводятся в тех же единицах, что и длина.

Перевод градусов в радианы: **радианы = градусы × π / 180**. Например, 90° ≈ 1.5708 рад.
