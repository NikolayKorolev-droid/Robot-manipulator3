Robot Manipulator — Python UI¶

Графический интерфейс для системы моделирования робота-манипулятора.

Модули¶

class ui.App[исходный код]¶

Базовые классы: Tk

Главное окно приложения Robot Manipulator UI.

Создаёт экземпляр манипулятора через rm_create_manipulator(), настраивает три вкладки (Сборка, Управление, Позиция/структура) и освобождает манипулятор при закрытии.

destroy() → None[исходный код]¶

Destroy this and all descendants widgets. This will end the application of this Tcl interpreter.

on_add_link()[исходный код]¶

Обработчик: добавление звена. По типу (MovableLink/Gripper/Camera) вызывает соответствующую функцию DLL. Автоматически определяет предыдущее звено как ID-1.

on_calc_pos()[исходный код]¶

Вычислить глобальную позицию звена и показать её в UI.

on_close_gripper()[исходный код]¶

Закрыть захват (для Gripper).

on_open_gripper()[исходный код]¶

Открыть захват на указанный угол (для Gripper).

on_print_structure()[исходный код]¶

Печать структуры манипулятора в stdout (консоль).

on_set_dir()[исходный код]¶

Установить ориентацию звена (pitch/yaw/roll) через DLL.

on_take_photo()[исходный код]¶

Сделать «снимок» (для Camera). Реализация вывода — в C++ коде.

Класс App¶

Главное окно приложения. Содержит три вкладки:

  • Сборка манипулятора — добавление звеньев (MovableLink, Gripper, Camera)

  • Управление — установка ориентации, открытие/закрытие захвата, снимок камеры

  • Позиция/структура — расчёт координат звена, вывод структуры в консоль

Взаимодействие с DLL¶

Модуль ui загружает RobotManipulator.dll через ctypes и вызывает C-API функции (rm_create_manipulator, rm_add_link, rm_set_direction и т.д.). См. также документацию C++ (Doxygen).
