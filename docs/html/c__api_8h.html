Подробное описание

C-совместимый API библиотеки Robot Manipulator.

Экспортирует функции с префиксом rm_ для вызова из Python (ctypes) и других языков. Коды возврата: 1 — успех, 0 — ошибка, -1 — ManipulatorException.
