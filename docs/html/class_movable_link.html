Подробное описание

Базовый класс для подвижного звена робота-манипулятора

Хранит длину звена, ориентацию (pitch, yaw, roll) относительно предыдущего звена и образует цепочку через prev_id_. Ось Z направлена вдоль предыдущего звена.
